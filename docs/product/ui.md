# 界面与交互约定

## 定位

界面是配置工作台，主要用户路径为编辑配置 → 评估 → 发布 → 查看历史与回滚。业务语义由上下文文档维护；本文件只维护导航、表现与交互结果。

## 信息架构

- 登录页：账号、密码、明确错误、退出后的会话状态。
- Flag 列表：全局环境切换、搜索、启停筛选、名称/Key/状态/版本/更新时间、新建入口。
- Flag 详情：基本配置、规则、版本、操作历史四个标签页；有独立 URL，刷新可恢复选定 Flag 与环境。
- 新建/编辑面板：必要字段、就地校验、保存状态；失败保留输入。
- 评估控制台：选择环境和 Key、输入属性 JSON、查看结果/版本/来源与逐条判断；从详情进入时带入当前对象。
- 复制/发布弹窗：来源版本、目标环境、变更差异和操作结果。
- 回滚入口：查看版本差异和目标内容，再执行恢复。

列表、详情与控制台可以共享路由外壳，不以页面或路由数量作为完成指标。

侧栏条目保持图标与文字横向居中，选中项使用主色文字、图标及浅色背景；较窄桌面只显示图标时保留可访问名称和提示，移动端使用横向导航。

## 视觉与状态

采用中文文案、英文技术字段、系统字体、紧凑清晰的表格和表单。浅色为默认，提供深色；中性表面与单一主操作色，状态使用明确语义色并同时提供文字。

每个异步区域提供加载、空、失败和成功反馈。停用、无权限、未保存与冲突状态要可辨识，不能仅靠降低透明度解释原因。

避免把工程实现细节写入产品流程；只有优先级方向、灰度标识、版本冲突等影响用户决策的规则需要解释。

## 文字与排版

标题、正文和辅助信息使用统一尺度与语义颜色，不在每页单独定义接近的字号。页面标题 22px、区块标题 16px、正文 14px、字段标签 13px、辅助信息 12px。标题字重 600～650，标签 500，正文与说明 400。正文行高 1.65，辅助长说明 1.7，不靠大段加粗制造层级。

列表、评估和服务概览共用 PageHeader，只显示标题与一行简短说明，主操作对齐标题区域。环境与身份只在顶部显示，不在侧栏或普通页头重复；详情保留当前对象的环境与 revision。

Key、JSON、seed、规则运算符等技术值用等宽字体。字段标签、控件和提示形成同一组；提示低一级，但错误与权限信息保留清晰对比。规则条件突出属性/比例，返回值单独一行。历史动作与 revision 一行，操作者/时间及环境/Key 分行。评估结果突出返回值，判断轨迹分别显示规则标识和状态。长文本主动换行或提供可识别的截断；只有列表表格保留内部横向滚动，不让整个页面溢出。

## 组件与交互

共享交互控件使用官方 shadcn/ui 源码及 Radix：Button、Input、Textarea、Label、Checkbox、Select、Tabs、Dialog、NavigationMenu、Pagination、Collapsible、Tooltip；内容与反馈使用 Table、Badge、Card、Alert。组件及来源归 presentation/components/ui，业务适配器归 presentation/components，不进入应用或领域层。普通表单、标题、正文、列表及链接保留语义 HTML。

所有下拉共用受控 Dropdown，支持键盘、禁用项和 portal，业务空值由适配器转换，不泄漏到 API。选择菜单有可辨识选中态、有界高度及一致的紧凑文字；弹窗中的 Escape 先关闭选择菜单并返回触发点，再关闭弹窗。分页使用真实禁用 Button；审计详情使用 Collapsible。图标按钮保留可访问名称，显式提示使用 Tooltip，不能因弹窗自动聚焦关闭按钮而拦截第一次 Escape。

## 保存与排序

- 表单编辑属于临时状态，保存成功后读取后端新 revision。
- 遇到冲突时展示最新版本入口，保留本地输入；不能自动重试旧写入覆盖新数据。
- 拖拽过程中即时跟随，释放后提交完整顺序；失败恢复权威顺序并保留明确反馈。
- 排序提供键盘和上移/下移操作，结果遵守与拖拽相同的提交契约。
- 拖拽的测量、碰撞、位移和传感器由 dnd kit Sortable 管理；拖动手柄使用 Button。聚焦手柄后的 ↑/↓ 立即移动；空格开始拖动、方向键移动、空格确认，Escape 取消不产生保存请求。
- 复制/发布与回滚展示差异和目标环境；错误不得关闭弹窗并丢失目标选择。

## 可读配置与变更

规则条件将 equals/in 展示为「等于/属于任一值」，保留原属性名、精确期望值与 true/false，结合优先级和命中返回说明。历史默认显示具体摘要与版本变化，「查看变更详情」仅列变化的业务字段/规则；技术 ID/时间不进入业务对比，原始记录通过「查看原始数据」折叠保留。未知或不兼容的记录明确提示无法生成摘要，不猜测内容。

发布明确固定源版本、目标环境/Key、按预览生成的新 revision 和历史保留；回滚确认内显示同一份差异及将生成的新 revision。冲突后必须刷新差异再确认，摘要不能替代后端版本与权限校验。seed 变化说明分组可能改变，其具体值在原始配置数据中保留。

原始 JSON 排版只添加空白，不重新序列化数字；复制审计时复制完整原始文本，准确反馈成功/失败并允许重试。实现与检查见 [可读变更验证](../specs/010-readable-changes/verification.md)。

## 可访问性与验证

图标按钮有名称，输入有 label，状态可被辅助技术感知。弹窗管理焦点、Tab 顺序、Escape 和关闭后的焦点返回；长内容可滚动。窄屏避免表单和动作遮挡。

动效只用于反馈和空间连续性，保持简短可中断，并响应 `prefers-reduced-motion`。主题颜色保持对比度，不能把颜色当作唯一状态标识。

局部样式修改验证真实组件在浏览器中的渲染，至少检查受影响主题、桌面/窄屏、长文本、焦点及适用的错误/禁用状态。无行为变化时不强制新增永久截图基线或 E2E；行为测试按 [测试矩阵](../testing/TESTING_MATRIX.md) 下沉。
