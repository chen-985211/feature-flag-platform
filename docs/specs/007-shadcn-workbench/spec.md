## 目标与事实归属

将功能工作台整理为清晰、紧凑、一致的真实业务界面。Presentation 拥有布局、输入、焦点和反馈；Flags/Identity/Audit 的领域、用例、revision/权限与持久化仍由既定 owner 维护。前端保持 DDD + Clean，仅 UI primitives 引入 React/Radix；不能将 HTTP adapter 或业务判断移入共享组件。

## 行为与视觉

中性浅/深主题、单一蓝色主操作、系统字体、统一控件高度/边框/间距。侧栏负责导航，顶部负责环境与身份；列表集中筛选和表格，新建/编辑以有界弹窗承载，详情四个标签可键盘操作并保持 URL。评估输入/结果分区，规则/版本/历史扫描清楚，不增加装饰性仪表盘或工程说明。

shadcn 的 Button/Input/Textarea/NativeSelect/Checkbox/Label/Badge/Table/Tabs/Dialog 等来自官方 registry，源码进入 presentation，依赖固定，使用统一语义 token。NativeSelect 保留浏览器原生选择行为；Dialog/Tabs/Checkbox 使用 Radix。既有业务输入、中文命名、权限限制、错误和本地输入保留语义不变。

## 不变量与边界

保存成功才更新版本和缓存；失败/冲突保留输入，不能盲目重试。复制/发布保持所选源版本与目标 revision；回滚仍先显示差异并确认。Dialog 有可访问名称、Tab 焦点边界、Escape/关闭返回触发点，提交中不误关闭；详情 tab 有独立 URL，刷新保持选项。只读/停用/错误明确显示。

390px、桌面、长文本、浅/深主题、loading/empty/error/focus/disabled 均有实际验证。减少动效时保持反馈但不移动大面积内容。

## 风险与限制

Radix 引入 ARIA tab/portal 语义，应更新实际角色定位而不删断言。样式从全局原生元素规则迁移为组件 token，避免旧 CSS 覆盖框架。保留当前 18090 人工验收数据；测试 fixture 增加独立端口配置，更新前端预览复用该后端。Docker 留到 CI 最后验收，本次不将其标为通过。
