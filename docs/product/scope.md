# 本次项目范围

## 基线

本次交付是 Feature Flag 与灰度规则平台，覆盖 [原题](../../question.md) 全部必做项及全部扩展项。“配置版本、回滚或乐观锁”“复制或发布”“前端测试或在线部署”在本次均按全部实现验收。

技术与工程方式已确定：React + Go + PostgreSQL；前后端 DDD + Clean；大任务 SDD，行为变更 TDD；测试严格遵循金字塔。当前只完成方案和规范，应用功能全部待实现。

原题的 48 小时提交窗口与建议 6～8 小时投入是题面约束，不由文档创建时间推算新的截止时间。扩展项不替代原题最低要求。

## 工程与交付范围

完整源代码、SQL 迁移、演示配置与用户、环境变量示例、本地启动入口、必要测试、README、设计取舍、已完成/未完成/限制说明、AI 对话或操作记录均纳入交付。

所有界面操作使用本项目 Go API；核心数据持久化到 PostgreSQL。界面应有加载、空、错误、成功、禁用与冲突反馈，且关键流程支持键盘操作。

产品信息架构见 [界面约定](ui.md)，阶段划分见 [交付计划](../delivery/roadmap.md)。具体 API 与数据 schema 在对应 Large 任务的 Spec/Plan 中形成，不能直接由某个 UI 组件决定。

## 范围变更

业务细化由对应上下文文档维护。变更验收、引入新能力或改变既定规则时，按大任务流程记录来源、影响和确认状态；不把未完成项改名为可选项来宣称交付完成。

本项目当前聚焦单个团队的配置管理；多租户、SDK 分发、实时推送、SSO、自助注册、通用工作流与审批流不属于已经确定的交付能力。
