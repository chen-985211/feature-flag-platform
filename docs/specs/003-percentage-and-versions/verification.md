## 有效 Red 与修复

- Go 领域固定向量、比例边界、缺失标识及混合规则行为，恢复/差异与应用预览/回滚先运行行为 Red，实施后 Green。独立 Node 标准 crypto 提前计算向量，不复制被测 Go 算法生成期望。
- 真实 PostgreSQL 的百分比保存暴露空 RawMessage 序列化失败；百分比期望值归一为空指针后，保存、读取与评估通过。
- 旧快照兼容回归实际发现：新增默认 Kind 字段开销使原本有效的大快照不可读。持久化省略 attribute 默认 Kind，领域大小检查同样省略，保持原 24 KiB 限制后转绿。
- 前端百分比转换、消费契约、版本界面与比例表单的行为 Red 后实施；精确小数使用字符串转整数基点，拒绝超过两位小数。
- 第二条 E2E 发现 select 包裹式 label 的精确名称包含选项文本；改为明确 htmlFor/id 后通过。随后真实版本差异接线失败，HTTP 回归复现 percentage 的 expected_json 被转成字符串 "null"；修复差异 DTO 转换，保留前端形状校验后通过。
- 完整恢复复核新增不同 seed 的历史场景：快照恢复成功，但关系表仍保留当前 seed，真实数据库断言 Red。统一 Save 更新 seed 后，关系表/快照一致，恢复与回归通过。
- Knip 检出未使用的公开类型：移除仅内部使用的导出并采用明确类型导入，无忽略规则。编译、测试期望数量修正等基础设施问题不计为目标行为 Red；已有行为的追加验证不虚构先失败。
