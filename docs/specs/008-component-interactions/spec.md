# UI Spec：完整交互组件与页头收敛

状态：已完成自动验收，基线 914a556，结果绑定包含本记录的本地提交。用户提供截图，要求删除左下角重复身份，改善列表页头和下拉框，并明确「全面替换手写的交互控件」。继续遵守不使用浏览器工具、由自动测试兜底的指令。

## 范围与 owner

Presentation 拥有控件、选中值、焦点、折叠和反馈，现有上下文应用契约保持不变。下拉由 NativeSelect 迁移到官方 Radix Select，导航、分页、历史折叠、图标提示用官方对应组件；卡片和错误/权限提示用 Card/Alert。普通标题、正文、列表、定义列表及表单保留语义 HTML。按用户「全面替换」要求，规则排序的原生 drag/位移/碰撞也替换为原定 dnd kit；RuleOrder 保留保存、乐观顺序、冲突恢复及权限 owner。

顶部是唯一身份与环境入口。页面标题区不重复显示「工作空间 / environment」，只保留标题与一行简短说明，主操作对齐。详情的环境/revision 是当前对象的有用元信息，保留。

## 不变量与边界

所有下拉受控，标签名称、实际业务值、空选择、disabled 与异步版本列表保持一致；禁止选 disabled 项。键盘可打开、选择和关闭菜单；Dialog 内选择后 Escape 优先关闭菜单，焦点返回选择触发点，下一次 Escape 才关闭 Dialog。保存中禁用、输入/版本冲突保留与权限判断继续有效。

环境切换更新 URL；从详情切环境回列表，保留其他有效参数。列表筛选重置 offset，规则选项不改变 exact JSON/百分比基点语义；版本选择保留固定 revision。历史默认折叠，展开后显示原始审计内容。分页使用真实 disabled Button，导航保留 URL 与选中态。
